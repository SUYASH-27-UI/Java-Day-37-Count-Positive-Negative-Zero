# Java Day 37 - Count Positive, Negative and Zero Elements

## Description
This Java program counts the positive numbers, negative numbers, and zeros in an integer array.

## Example
**Array:** `{10, -5, 0, 8, -2, 0, 15}`

**Output:**
- Positive numbers: 3
- Negative numbers: 2
- Zeros: 2

## Concepts Used
- Arrays
- For Loop
- If-Else If-Else
- Counter Variables

## How to Run
1. Save the code as `Main.java`.
2. Compile using `javac Main.java`.
3. Run using `java Main`.
